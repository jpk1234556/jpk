## Introduction

Welcome to the Property Management System Property Owner User Manual. This guide will help you navigate and utilize all the features available to property owners in the system.

As a property owner, you can manage:
- Your properties and units
- Tenant information and lease details
- Maintenance requests for your properties
- Payment tracking
- Generate reports on your properties

## Getting Started

### Account Registration
Before you can log in, your account must be approved by an administrator:
1. An administrator must create your account or you must register through the system
2. An administrator must approve your account and set your role to "Property Owner"
3. You will receive notification when your account is approved

### Login Process
1. Navigate to the property owner login page
2. Enter your username and password
3. Click the "Login" button
4. You will be redirected to your dashboard

### Navigation
The property owner interface consists of the following main sections:
- Dashboard: Overview of your properties and key metrics
- Properties: Manage your properties
- Units: Manage units within your properties
- Tenants: Manage tenant information
- Maintenance: Handle maintenance requests
- Payments: Track tenant payments
- Reports: Generate reports on your properties

## Dashboard Overview

The property owner dashboard provides a quick overview of your key metrics:
- My Properties: Number of properties you own
- Total Units: Total number of units across all your properties
- Occupied Units: Number of units currently rented
- Pending Requests: Number of maintenance requests awaiting attention

### Dashboard Features
- Quick access to recent activities
- Graphical representation of occupancy rates
- Upcoming lease expirations
- Recent payment summaries
- Maintenance request status indicators

### Dashboard Refresh
- The dashboard automatically refreshes every 5 minutes
- Click the "Refresh" button to manually update the statistics
- Export dashboard data using the "Export Data" button

## Property Management

### Viewing Your Properties
To view properties you own:
1. Click on the "Properties" link in the navigation menu
2. You will see a list of all properties assigned to you
3. Use the search bar to filter properties by name or type
4. Sort columns by clicking on the column headers

### Adding Properties
Note: Only administrators can create new properties. If you need to add a property, contact your system administrator.

### Editing Your Properties
To edit a property's information:
1. Go to the Properties page
2. Find the property you want to edit
3. Click the "Edit" button next to its name
4. Make the necessary changes (name, type, address)
5. Click "Save"

### Property Details
- View property statistics including occupancy rates
- See maintenance requests for the property
- View payment history for the property
- Access property documents and photos

## Unit Management

### Viewing Units
To view units within your properties:
1. Click on the "Units" link in the navigation menu
2. You will see a list of all units in your properties
3. Filter units by property or status using the filter options
4. Sort units by clicking on column headers

### Creating Units
To add a new unit:
1. Go to the Units page
2. Click the "Add New Unit" button
3. Fill in the required information:
   - Unit Number
   - Unit Type (e.g., Apartment, Room)
   - Capacity (number of occupants)
   - Price (monthly rent)
   - Status (Available, Occupied, Maintenance)
   - Property (select from your properties)
4. Add unit description and amenities (optional)
5. Click "Create Unit"

### Editing Units
To edit a unit's information:
1. Go to the Units page
2. Find the unit you want to edit
3. Click the "Edit" button next to its name
4. Make the necessary changes
5. Click "Save"

### Deleting Units
To delete a unit:
1. Go to the Units page
2. Find the unit you want to delete
3. Click the "Delete" button next to its name
4. Confirm the deletion when prompted

### Unit Status Management
- Change unit status based on occupancy or maintenance needs
- Set units to "Available" when ready for new tenants
- Mark units as "Maintenance" when repairs are needed
- Update status to "Occupied" when tenants move in

## Maintenance Requests

### Viewing Maintenance Requests
To view maintenance requests for your properties:
1. Click on the "Maintenance" link in the navigation menu
2. You will see a list of all maintenance requests for your units
3. Filter requests by property, unit, or priority
4. Sort requests by clicking on column headers

### Creating Maintenance Requests
To submit a new maintenance request:
1. Go to the Maintenance page
2. Click the "Add New Request" button
3. Fill in the required information:
   - Title
   - Description
   - Priority (Low, Medium, High)
   - Status (Pending, In Progress, Completed)
   - Unit (select from your units)
4. Attach photos or documents (optional)
5. Click "Submit Request"

### Updating Maintenance Requests
To update the status of a maintenance request:
1. Go to the Maintenance page
2. Find the request you want to update
3. Click the "Edit" button next to its name
4. Change the status as needed
5. Add notes about work progress (optional)
6. Click "Save"

### Deleting Maintenance Requests
To delete a maintenance request:
1. Go to the Maintenance page
2. Find the request you want to delete
3. Click the "Delete" button next to its name
4. Confirm the deletion when prompted

### Maintenance Tracking
- Track repair costs and expenses
- Monitor average resolution times
- Schedule preventive maintenance
- Maintain vendor contact information

## Reports

The system provides several types of reports for property owners:

### Income Report
Shows financial data for your properties including:
- Total income over a specified period
- Income broken down by property
- Monthly income trends
- Recent payments
- Outstanding balances

To generate an income report:
1. Click on the "Reports" link in the navigation menu
2. Select "Income" from the report type dropdown
3. Optionally specify a date range
4. Optionally select a specific property
5. Click "Generate Report"
6. Export the report to PDF or CSV using the export buttons

### Occupancy Report
Shows occupancy statistics for your properties including:
- Overall occupancy rate
- Occupancy by property
- Total units vs. occupied units
- Vacancy trends over time
- Average lease duration

To generate an occupancy report:
1. Click on the "Reports" link in the navigation menu
2. Select "Occupancy" from the report type dropdown
3. Optionally specify a date range
4. Optionally select a specific property
5. Click "Generate Report"

### Maintenance Report
Shows maintenance request statistics for your properties including:
- Total maintenance requests
- Requests by status (pending, in progress, completed)
- Requests by priority (low, medium, high)
- Average resolution time
- Maintenance costs by property
- Recent maintenance requests

To generate a maintenance report:
1. Click on the "Reports" link in the navigation menu
2. Select "Maintenance" from the report type dropdown
3. Optionally specify a date range
4. Optionally select a specific property
5. Click "Generate Report"

### Tenant Report
Shows tenant-related statistics for your properties including:
- Total number of tenants
- Active vs. expired leases

- Recent tenant registrations
- Tenant retention rates
- Lease expiration forecasts

To generate a tenant report:
1. Click on the "Reports" link in the navigation menu
2. Select "Tenants" from the report type dropdown
3. Optionally specify a date range
4. Optionally select a specific property
5. Click "Generate Report"

### Custom Reports

## API Integration

The Property Management System provides a comprehensive REST API for integration with external systems.

### Authentication
All API requests require authentication using token-based authentication:
1. Obtain an authentication token by logging in via the API
2. Include the token in the Authorization header: `Authorization: Token YOUR_TOKEN`

### Available Endpoints
Refer to the [API Documentation](API_DOCUMENTATION.md) for detailed information about all available endpoints:
- Property Management API
- Unit Management API
- Tenant Management API
- Maintenance Request API
- Payment Tracking API
- Property Owner Module API

### Rate Limiting
- 1000 requests per hour per user
- Exceeding limits will result in 429 (Too Many Requests) responses
- Check the `X-Rate-Limit-Remaining` header to monitor your usage

### Webhooks
- Configure webhook URLs for real-time notifications
- Supported events include:
  - New tenant registration
  - Payment received
  - Maintenance request created
  - Lease expiration warnings

### Data Export
- Export data in JSON, CSV, or XML formats
- Schedule automated exports
- Configure export filters and transformations

## Troubleshooting

### Common Issues

#### Login Problems
- Ensure you're using the correct username and password
- Check that your account has been approved by an administrator
- Contact system support if you continue to have issues

#### Access Denied Errors
- Ensure you're trying to access only your own properties and units
- Remember that you can only manage data related to your properties
- Contact an administrator if you believe you should have access to additional properties

#### Report Generation Issues
- Ensure date formats are correct (YYYY-MM-DD)
- Verify that the selected date range contains data
- Refresh the page and try again

#### Unit Management Issues
- Verify that all required fields are filled
- Ensure the selected property belongs to you
- Check for duplicate unit numbers

#### Tenant Creation Issues
- Verify that all required fields are filled
- Ensure the selected unit belongs to you
- Check that lease dates are valid

#### Maintenance Request Issues
- Verify that all required fields are filled
- Ensure the selected unit belongs to you
- Check that priority and status values are valid

#### Payment Recording Issues
- Verify that all required fields are filled
- Ensure the selected tenant belongs to you
- Check that payment amounts are positive

#### API Integration Issues
- Verify your authentication token is valid
- Check that you have the required permissions for the endpoint
- Review the API documentation for correct request format

### System Performance
- If the system is running slowly, try clearing your browser cache
- Close other browser tabs to free up memory
- Contact support if performance issues persist
